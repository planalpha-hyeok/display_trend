# 분기 전망 리포트 절차

1. `prompts/common.md` 절차를 따른다.
2. 템플릿: `templates/quarterly.md`
3. 회고 대상: 직전 분기. 전망 대상: 실행일이 속한 분기.
4. 먼저 GitHub `reports/monthly/`와 `reports/weekly/`에서 직전 분기 리포트를 읽는다.
   그 위에 조사기관 공개 전망, 제조사 발표, 정책 일정을 추가로 검색한다.
5. 전망마다 근거(출처)와 확신 정도를 적는다. 근거 없는 전망은 쓰지 않는다.
6. 파일 이름: `reports/quarterly/YYYY/YYYY-QN_분기.md` (YYYY-QN = 전망 대상 분기, 예: 2027-Q1)
7. Drive 폴더: 3_분기
