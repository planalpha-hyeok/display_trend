# 월간 요약 리포트 절차

1. `prompts/common.md` 절차를 따른다.
2. 템플릿: `templates/monthly.md`
3. 대상 기간: 직전 달 1일 ~ 말일.
4. 먼저 GitHub `reports/weekly/`에서 대상 기간에 해당하는 주간 리포트를 모두 읽는다.
   주간 리포트 내용을 기본 자료로 쓰고, 빠진 부분만 추가 검색한다.
   주간 리포트가 없거나 부족하면 그 사실을 리포트 머리말에 적는다.
5. 파일 이름: `reports/monthly/YYYY/YYYY-MM_월간.md` (YYYY-MM = 대상 달)
6. Drive 폴더: 2_월간
