# 게시판용 텍스트 작성 규칙

사내게시판은 HTML·Markdown 서식이 적용되지 않으므로 서식 없는 텍스트로 만든다.

- Markdown 기호(#, *, **, |, ```, [](링크 문법))를 쓰지 않는다.
- 제목은 【 】로 감싼다. 예: 【1. 국내 동향】
- 목록은 "- " 또는 "1) " 를 쓴다.
- 표는 쓰지 않는다. "항목: 내용" 형식의 줄로 바꾼다.
- 링크는 URL을 그대로 적는다.
- 분량: 원본의 핵심만 담아 A4 1~2장 정도. 맨 아래에 다음 두 줄을 넣는다.
  상세 리포트(Google 문서): <링크>
  원본 보관(GitHub): <링크>
